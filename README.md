# Assignment2-EM

##Description
#This project uses the penguins.csv, which contains information about 3 species of penguins including the following species: Adelie, Chinstrap, and Gentoo. The data set includes information such as the body mass, bill length, and information about the islands.

#Analysis script
#The script:
# - Generates summary statitstics for the dataset
# - Counts the number of penguins from each species
# - Calculates the average body mass for each species
# - Merges the species count and average body mass into a table and saves it into penguins_results.csv.

#How to reproduce the Analysis
# 1. Clone the GitHud repository into your computer
# 2. Use RStudio and set the working directory to the repository folder
# 3. open Assignment2.R
# 4. Install dplyr package and run the R script

#The script will load the penguins.csv, run the analysis and save the results penguins_results.csv into the folder
